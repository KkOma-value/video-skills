# Field Archive Film 生成模板

请使用 `field-archive-film` 风格，为以下主题设计一支原创短片。

## 输入

- 主题/产品：{{SUBJECT}}
- 核心价值：{{CORE_IDEA}}
- 时长：{{DURATION_SECONDS}} 秒
- 比例：{{ASPECT_RATIO}}
- 投放平台：{{PLATFORM}}
- 风格强度：{{STYLE_STRENGTH|balanced}}
- 必须出现：{{MUST_INCLUDE}}
- 禁止出现：{{MUST_AVOID}}

## 创作要求

1. 将核心价值转译成一个可以被观察、测量或显影的实体实验。
2. 选择 3–5 个视觉母题，并构建贯穿全片的图形链。
3. 主要使用顶视、正面和微距镜头；人物只出现手部。
4. 使用雾灰绿、冷白、石墨黑、档案棕和少量深蓝。
5. 让物体通过展开、对齐、称量、吸附、聚集和归位完成叙事。
6. 活跃段落镜头长度控制在 0.3–1.2 秒，结尾保留 4–6 秒。
7. 以硬切、图形匹配和动作匹配为主，不使用模板化故障或旋转转场。
8. 结尾将复杂实验结果简化为一个全新的品牌符号或短句。
9. 不复制任何参考品牌、原文案、原镜头顺序或具体道具组合。

请依次输出：创意概念、视觉母题、时间轴、分镜表、总提示词、分镜提示词、负面提示词、声音设计和原创性检查。
